# A-3DPathfindingStudy
Estudo do Codigo de A-Star baseando se na modificação de um codigo 2D para um 3D, com a capacidade de identificar obstaculos, e com um sistema de debug.

3D A-Star Pathfinding System*
Projeto dedicado ao estudo e evolução do algoritmo A* (A-Star), baseando-se na transição de um sistema de navegação 2D para um grid tridimensional (3D). O código do grid utilizado como base já havia passado por modificações anteriores em outro projeto de estudo, servindo agora como ponto de partida estrutural para esta nova etapa.

O sistema foi reestruturado para suportar a complexidade do novo espaço, explorando como a adição de um terceiro eixo impacta a avaliação de nós (G-cost, H-cost e F-cost), a descoberta de vizinhos e as fórmulas de cálculo de distância.

Além da navegação principal, esta implementação conta com a capacidade de identificar obstáculos dentro do espaço tridimensional e inclui um sistema improvisado de debug, facilitando a visualização e a análise do comportamento do algoritmo durante a busca pelo melhor caminho.
